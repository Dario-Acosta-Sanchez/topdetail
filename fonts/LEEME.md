# Tipografías de la web

Copiadas de Google Fonts el 17-11-2026 (solo los juegos `latin` y `latin-ext`) para que la web no pida nada a Google al cargarse.
Todas tienen licencia SIL Open Font License 1.1 (uso libre, también comercial): Cormorant Garamond, Jost, Inter Tight, Anton y Caveat.
Las reglas `@font-face` están dentro de `index.html` (`<style id="fonts">`); `fonts.css` es la misma copia.
