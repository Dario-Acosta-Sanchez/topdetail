# Top Detail Garage · demo móvil

Demo interactiva para móvil de Top Detail Garage (detailing en Fernán Núñez, Córdoba): el A7 en el taller, cuatro servicios (limpieza, tintado, pintura y extras), paso automático de antes a después y acercamiento en vídeo a la pintura.

🔗 **[topdetail.puntozerosl.es](https://topdetail.puntozerosl.es)**

HTML, CSS y JS sin dependencias. Fotos y vídeo generados con Gemini.
